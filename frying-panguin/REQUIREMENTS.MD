# Goal

Create "Frying Panguin", an instantly playable, fully top-down 2D arctic browser rogue-like with a snappy repeatable game loop.

# Requirements

## Technical Requirements

- Build specifically for modern browsers, without a required build step or runtime dependencies.
- Ideally load in under one second.
- Fill the browser viewport immediately. Remove sound and fullscreen buttons on all layouts; audio startup and lifecycle work independently of removed controls.
- Use a fully overhead 2D view for the player, enemies, objects, and environment.
- Support keyboard play and a proper analog mobile joypad with pointer capture, dead zone, proportional movement, and clean release/cancel behavior.
- Keep game simulation independently testable without a DOM, with rendering and input integration separate from simulation rules. Render terrain, shops, and sprite footprints using the simulation's shared geometry and coordinates.
- Cache immutable terrain separately from mutable per-run scenery. Visible obstacle damage/destruction, collision, and automated navigation must follow the current simulation obstacle state.
- Optional browser-validation tools must remain development tooling; playing the shipped game must not require them.
